# 30-Day Communication & Confidence Transformation

Personal operating system for **ACT → SPEAK → THINK → EXPLAIN**:

- Zero Hesitation
- Communication & English
- Impromptu Thinking
- Technical Communication

Built with **Next.js** (App Router), **Tailwind CSS**, **localStorage** persistence, dark mode, timers, scoring, streaks, XP/levels, weekly reviews, progress charts, and a Day 30 Final Boss screen.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deploy on Vercel

1. Push this repo to GitHub (or import from your machine).
2. Go to [vercel.com](https://vercel.com) → **Add New Project** → import the repo.
3. Framework preset: **Next.js** (defaults are fine).
4. Deploy.

No environment variables required for v1 — all progress is stored in the browser.

## Features

- Dashboard command center (day progress, streaks, pillar cards, today’s mission)
- Per-day missions with nervousness scale, timer (THINK/SPEAK), scoring, reflections
- Pillar detail pages (rules, frameworks, technical practice projects)
- Progress analytics (radar + line/bar charts)
- Weekly reviews (days 7, 14, 21, 28)
- Final Boss (Day 30) + transformation score

## Philosophy

You don't need to feel confident to act confidently.  
You don't need to know the answer immediately to think well.  
You don't need perfect English to communicate clearly.
